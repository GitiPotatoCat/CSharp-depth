Dictionary<TKey, TValue>

A hash-based collection of key-value pairs. Average O(1) lookup, insert, and delete — the default choice when you need to find values by a unique key.

Lookup
O(1)
average, hash-based
Insert
O(1)
amortized, may resize
Delete
O(1)
by key

When to use

Reach for Dictionary when you need fast lookups by a unique key and insertion order does not matter. It is the standard map type in .NET — choose SortedDictionary only when ordered traversal is required, and ConcurrentDictionary only when multiple threads write to the same map.

Example

var users = new Dictionary<int, string>
{
    [1] = "Alice",
    [2] = "Bob",
    [3] = "Carol"
};

// O(1) average lookup
if (users.TryGetValue(2, out var name))
    Console.WriteLine(name);

// Safe add — throws on duplicate key
users.Add(4, "Dan");

// Upsert pattern
users[4] = "Daniel";
