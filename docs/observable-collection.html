ObservableCollection<T>

A list that raises CollectionChanged and PropertyChanged events whenever items are added, removed, replaced, moved, or reset. Purpose-built for UI data binding in WPF, WinUI, MAUI, Avalonia, and Uno — every bound control refreshes automatically when the collection mutates.

Lookup
O(1)
indexed access like List<T>
Insert
O(1) / O(n)
append amortized; middle shifts
Delete
O(n)
shifts + event dispatch

When to use

Use ObservableCollection as the ItemsSource of any data-bound control when the item list can change at runtime — editable grids, chat logs, live search results, dynamic task boards. For view-model backing with no UI binding, a plain List<T> is lighter and faster. When thread-safety matters across UI and background workers, mutate only on the UI thread — or use a dispatcher to marshal.

The events

collection change consumers ───────────────── ───────── Add / Insert ──┐ Remove / RemoveAt │ CollectionChanged ◄── ItemsControl, Replace (this[i] = x) ├──▶ NotifyCollectionChanged ListView, Move │ EventArgs with Action DataGrid, Clear ──┘ any binding Count delta ──┬──▶ PropertyChanged("Count") Indexer change ──┴──▶ PropertyChanged("Item[]")
Thread affinity
ObservableCollection is not thread-safe, and event delivery is synchronous — handlers run on the thread that mutated the collection. UI frameworks forbid mutating bound collections off the UI thread; a background task calling Add will crash most XAML stacks. Marshal mutations through the dispatcher, or use a wrapper like BindingOperations.EnableCollectionSynchronization in WPF.

Example

// Create and bind — the ViewModel pattern
public ObservableCollection<TodoItem> Items { get; } = [];

// Subscribe to changes
Items.CollectionChanged += (sender, e) =>
{
    Console.WriteLine($"{e.Action}: {e.NewItems?.Count ?? 0} added, {e.OldItems?.Count ?? 0} removed");
};

// Every mutation raises CollectionChanged
Items.Add(new TodoItem("write docs"));   // Action = Add
Items.Insert(0, new TodoItem("plan"));    // Action = Add
Items[1] = new TodoItem("ship");          // Action = Replace
Items.Move(0, 1);                         // Action = Move
Items.RemoveAt(0);                           // Action = Remove
Items.Clear();                                // Action = Reset

// Seed from an existing sequence
var seeded = new ObservableCollection<string>(
    ["alpha", "beta", "gamma"]);

// Listen to property changes on the collection itself
((INotifyPropertyChanged)Items).PropertyChanged += (s, e) =>
{
    if (e.PropertyName == "Count") UpdateStatus();
};
