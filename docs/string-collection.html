StringCollection

A specialized, non-generic list that holds only string values. Introduced to sidestep the boxing overhead of ArrayList for string-heavy collections before generics arrived. With List<string> available on every platform, StringCollection lingers mainly as the backing store for settings files and auto-generated configuration code.

Lookup
O(1)
indexed access, typed string
Insert
O(1) / O(n)
append amortized; middle shifts
Delete
O(n)
shifts later elements
Use List<string> instead
StringCollection was created because ArrayList boxed nothing but caused the user to cast every read. Since strings are reference types there is no boxing to avoid — the whole point of this type was to offer typed access. List<string> does exactly that, with a richer API, LINQ support, and consistent behavior with every other generic collection. New code should always pick List<string>.

When to use

Almost never, in new code. StringCollection survives today because it is the type the Visual Studio settings designer emits for StringCollection-typed user settings and because a handful of framework APIs expose it. If you own the code, migrate to List<string>. If you do not, read and write through StringCollection and convert at the boundary.

Example

// Construct and populate
var tags = new StringCollection();
tags.Add("draft");
tags.Add("urgent");
tags.Add("review");

// AddRange accepts string[]
tags.AddRange(new[] { "ship", "done" });

// Indexer returns string directly — no cast needed
string? first = tags[0];                 // "draft"

// Standard list operations
tags.Insert(1, "high");
tags.Remove("done");
bool has = tags.Contains("urgent");
int  idx = tags.IndexOf("review");

// Enumeration yields string
foreach (string? tag in tags)
    Console.WriteLine(tag);

// Typical Properties.Settings integration
Properties.Settings.Default.RecentFiles ??= new StringCollection();
Properties.Settings.Default.RecentFiles.Add(path);
Properties.Settings.Default.Save();

// Bridge to the modern world
List<string> modern = tags.Cast<string>().ToList();

// And back, when an API requires StringCollection
var back = new StringCollection();
back.AddRange(modern.ToArray());
