Span<T>

A stack-allocated, type-safe view over a contiguous region of memory — whether that memory lives on the managed heap, the stack, or in unmanaged memory. Span slices arrays and buffers without copying or allocating, making it the foundation for high-performance .NET code.

Lookup
O(1)
direct pointer access
Slice
O(1)
no copy, no allocation
Allocation
0 B
stack-only, no GC pressure

When to use

Reach for Span<T> in hot paths — parsing, buffer manipulation, and numeric work — where you want to read or mutate a slice of memory without copying. Use ReadOnlySpan<T> for non-mutating views, especially over strings. Because Span is a ref struct, it cannot be stored on the heap, captured by async methods, or held past its owning scope — when those constraints bite, switch to Memory<T>.

Example

// Slice an array with no allocation
int[] source = { 1, 2, 3, 4, 5, 6 };
Span<int> window = source.AsSpan(1, 3);    // { 2, 3, 4 }
window[0] = 99;                              // mutates source[1]

// Stack allocation — no GC involvement
Span<byte> buffer = stackalloc byte[256];

// Zero-copy string parsing
ReadOnlySpan<char> text = "2026-04-21".AsSpan();
ReadOnlySpan<char> year = text[..4];
int y = int.Parse(year);                 // no substring alloc

// Bulk operations
Span<int> nums = source;
nums.Fill(0);
nums.Reverse();
var idx = nums.IndexOf(0);
Ref struct restrictions
Span<T> lives on the stack only. It cannot be a field of a class, boxed, stored in a Task, captured by a lambda, or used across an await or yield. When any of these are required, use Memory<T> instead — it is the heap-safe counterpart.

How to construct

SourceSyntaxDescription
From array array.AsSpan() Wraps an existing managed array with no copy.
From array range array.AsSpan(start, length) Slice view over a segment of an array.
Stack allocation stackalloc T[n] Allocates on the stack — bound to the enclosing method frame.
From pointer new Span<T>(ptr, length) Unsafe — wraps unmanaged memory. Use with care.
From Memory<T> memory.Span Materializes a Span for the duration of the current call.
From string text.AsSpan() Returns ReadOnlySpan<char> — strings are immutable.

Span<T> vs ReadOnlySpan<T>

AspectSpan<T>ReadOnlySpan<T>
Mutability Read and write access to underlying memory. Read-only view — no writes permitted.
String support Cannot wrap a string — strings are immutable. Preferred view for string slicing without allocation.
Conversion Implicitly converts to ReadOnlySpan<T>. Cannot be converted back to a mutable Span.
