Array

The base class for all arrays in .NET. Fixed-size, zero-indexed, and strongly typed — the fastest contiguous memory structure for indexed access. Every array in C# (like int[] or string[,]) ultimately derives from System.Array.

Lookup
O(1)
direct index access
Insert
O(n)
requires resize and copy
Delete
O(n)
requires shifting elements

When to use

Use an array when the number of elements is known up front and will not change, and when you need the fastest possible indexed access with minimal memory overhead. Prefer List<T> when the size is dynamic, Span<T> when you want to slice without allocating, and ImmutableArray<T> when the contents must never be mutated after creation.

Example

// Single-dimensional array
int[] numbers = { 10, 20, 30, 40, 50 };

// O(1) indexed access
int first = numbers[0];
int last  = numbers[^1];          // index from end

// Range slicing (returns a new array)
int[] middle = numbers[1..4];

// Search and sort (static helpers)
Array.Sort(numbers);
int idx = Array.BinarySearch(numbers, 30);

// Multi-dimensional
int[,] grid = new int[3, 3];
grid[1, 2] = 42;

// Jagged (array of arrays)
int[][] jagged = [[1, 2], [3, 4, 5], [6]];

// Resize — returns a new array, old one is discarded
Array.Resize(ref numbers, 10);

Properties

PropertyTypeDescription
Length int Total number of elements in all dimensions.
LongLength long Total element count as a 64-bit integer. Used for very large arrays.
Rank int Number of dimensions. Returns 1 for a vector, 2 for a matrix, and so on.
IsFixedSize bool Always true — arrays cannot be resized in place.
IsReadOnly bool Always false for standard arrays. May be true for read-only wrappers.
IsSynchronized bool Whether access is thread-safe. Always false for raw arrays.
SyncRoot object Object used to synchronize access for legacy locking patterns.

Array shapes

ShapeSyntaxDescription
Single-dimensional int[] The most common form. Zero-indexed vector of elements.
Multi-dimensional int[,] · int[,,] Rectangular grid stored as a single contiguous block of memory.
Jagged int[][] An array of arrays — each inner row can have a different length.
