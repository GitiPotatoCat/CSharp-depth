ConcurrentStack<T>

A fully lock-free, thread-safe LIFO stack. Every push and pop rewires a single head pointer via Interlocked.CompareExchange, so multiple producers and consumers operate in parallel without ever taking a lock. Backed by a singly-linked list of nodes, it shines when the most recently added item is the one you want next.

When to use

Reach for ConcurrentStack when threads share recent state and the most-recent-first order is what you want — undo buffers, speculative-work pools, snapshot save points, DFS frontiers in parallel graph search. For FIFO pipelines use ConcurrentQueue<T>, and for work-stealing pools where order does not matter use ConcurrentBag<T>. Each push allocates a node, so avoid this type as a hot path for pure value-type throughput.

How it works

head │ ▼ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ │ d │ → │ c │ → │ b │ → │ a │ → null └─────┘ └─────┘ └─────┘ └─────┘ ▲ │ push/pop here via Interlocked.CompareExchange singly-linked list of heap-allocated nodes. only the head pointer is shared state.
Count is approximate
Count walks the entire linked list — O(n) — and the result can be stale the moment it returns because other threads continue to push and pop during the walk. Use IsEmpty for cheap checks, and drain with while (TryPop(...)) rather than gating on Count. Allocating a node on every push also makes this type more GC-intensive than a lock-protected Stack<T> — measure before assuming lock-free is faster.

Example

// Construct — optionally seeded from any IEnumerable
var undo = new ConcurrentStack<Snapshot>();

// Push — lock-free on the head
undo.Push(Snapshot.Create(state));

// TryPop — lock-free, returns false when empty
if (undo.TryPop(out var s))
    Restore(s);

// TryPeek — snapshot read of the head
if (undo.TryPeek(out var head))
    Console.WriteLine(head.Id);

// Bulk push — a single CAS links a whole array onto the stack
undo.PushRange([s1, s2, s3]);

// Bulk pop — up to N items in one interlocked operation
var buffer = new Snapshot[16];
int n = undo.TryPopRange(buffer);        // LIFO, newest first

// Producer and consumer in parallel — zero locks
var work = new ConcurrentStack<int>();

var producer = Task.Run(() =>
{
    for (int i = 0; i < 1_000; i++) work.Push(i);
});

var consumer = Task.Run(() =>
{
    while (!producer.IsCompleted || !work.IsEmpty)
        if (work.TryPop(out var v))
            Process(v);
});

await Task.WhenAll(producer, consumer);

// Point-in-time snapshot — head → bottom order
int[] snap = work.ToArray();
