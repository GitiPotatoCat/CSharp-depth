ArrayList

A dynamic, resizable array of object references — the pre-generics ancestor of List<T>. Every element is stored as object, so reads require casting and values boxed at insertion. Kept around for interop with very old APIs; new code should use List<T> in every case.

Lookup
O(1)
indexed access, returns object
Insert
O(1) / O(n)
append amortized; middle shifts
Delete
O(n)
shifts later elements
Use List<T> instead
ArrayList predates generics. Every read returns object, so the compiler cannot catch type mismatches and every cast pays a runtime cost. Value types are boxed on the way in and unboxed on the way out, adding allocation and pointer indirection to what ought to be a contiguous array of primitives. List<T> eliminates every one of these costs at compile time — use it for all new code.

When to use

Only when you must interoperate with an API that still exposes ArrayList — typically a class from early .NET Framework days, a COM boundary, or serialized data from an old system. For anything new, List<T> is faster, safer, and offers a richer API. When the data is of mixed types, List<object> is still preferable — you keep the generic-collection semantics and can opt into element types where it matters.

Example

// Construct and populate — any reference or value works
var items = new ArrayList();
items.Add("Alice");            // string
items.Add(42);                 // int — boxed
items.Add(new Point(1, 2));    // struct — boxed

// Indexer returns object — cast required
string? name = (string?)items[0];
int    age  = (int)items[1];     // unbox

// AddRange accepts any ICollection
items.AddRange(new[] { "Bob", "Carol" });

// Insert, Remove, Sort all shift or reorder in place
items.Insert(0, "Zane");
items.Remove(42);                            // removes first match
items.Sort();                                  // requires IComparable items

// Enumeration yields object — cast on the fly
foreach (var o in items)
    Console.WriteLine(o);

// Bridge to the modern world — copy into a typed array or List
var names = items
    .Cast<object>()
    .OfType<string>()
    .ToList();

// Synchronized wrapper — coarse locking only
ArrayList safe = ArrayList.Synchronized(items);
