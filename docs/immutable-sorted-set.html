ImmutableSortedSet<T>

An immutable set of unique values kept in comparer-defined order, backed by a self-balancing AVL tree. Combines the deterministic iteration of SortedSet, the persistent-snapshot semantics of the Immutable family, and one unique capability absent from ImmutableHashSet — positional index access in O(log n).

O(log n)
tree descent by comparer
Add
O(log n)
rebuild spine, share nodes

O(log n)

When to use

Use ImmutableSortedSet when set membership must evolve over time and enumeration order must be stable — versioned leaderboards, interval sets in concurrent rule engines, tag sets that ship to logs, any audit-visible snapshot of unique values. For unordered immutable sets, ImmutableHashSet is leaner. For single-threaded ordered sets without revision needs, SortedSet<T> is faster.

Unique immutable capabilities
Unlike ImmutableHashSet, this set offers Min, Max, an integer indexer over its sorted contents, and IndexOf. Position in the set is meaningful — the third smallest element is cheap to retrieve. Useful for percentile reporting, bounded-window audits, and top-K style consumers built on an immutable snapshot.

Example

// Construct — collection expression, factory, or LINQ suffix
ImmutableSortedSet<int> scores = [88, 72, 95, 91];
ImmutableSortedSet<string> empty = ImmutableSortedSet<string>.Empty;

// Enumeration is sorted — 72, 88, 91, 95
foreach (var n in scores)
    Console.WriteLine(n);

// Min / Max — first-class and cheap
int lowest  = scores.Min;                  // 72
int highest = scores.Max;                  // 95

// Positional access — O(log n)
int third = scores[2];                     // 91
int idx   = scores.IndexOf(88);            // 1

// Mutations return a new set — original untouched
ImmutableSortedSet<int> withHundred = scores.Add(100);
ImmutableSortedSet<int> removed     = scores.Remove(72);

// Set algebra — each returns a new immutable set
ImmutableSortedSet<int> a = [1, 2, 3, 4];
ImmutableSortedSet<int> b = [3, 4, 5, 6];

ImmutableSortedSet<int> u   = a.Union(b);             // { 1, 2, 3, 4, 5, 6 }
ImmutableSortedSet<int> i   = a.Intersect(b);         // { 3, 4 }
ImmutableSortedSet<int> d   = a.Except(b);            // { 1, 2 }
ImmutableSortedSet<int> sym = a.SymmetricExcept(b);   // { 1, 2, 5, 6 }

// Efficient batch construction via a Builder
ImmutableSortedSet<int>.Builder builder =
    ImmutableSortedSet.CreateBuilder<int>();
for (int n = 0; n < 1_000; n++) builder.Add(n);
ImmutableSortedSet<int> sealed = builder.ToImmutable();

// Descending order via reversed comparer
ImmutableSortedSet<int> desc = ImmutableSortedSet
    .Create<int>(Comparer<int>.Create((x, y) => y.CompareTo(x)))
    .Union(scores);

// Reverse enumeration — top to bottom
foreach (var n in scores.Reverse())
    Console.WriteLine(n);             // 95, 91, 88, 72
