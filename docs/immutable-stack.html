ImmutableStack<T>

The simplest persistent collection in the BCL — a singly-linked list of nodes where the head is the top of the stack. Every Push and Pop returns a new stack that shares every remaining node with the old one. The canonical functional data structure, and the one with the tightest structural sharing of any immutable type.

Push
O(1)
single new node, old head linked
Pop
O(1)
return tail, no allocation
Peek
O(1)
reads head value

When to use

Reach for ImmutableStack when the LIFO shape matters and each state must stand as a lasting snapshot — recursive descent parsers that thread context through alternatives, undo chains where every step is preserved, backtracking search where branches fork a shared history. For multi-writer concurrent LIFO use ConcurrentStack. For pure single-threaded work, Stack<T> is faster.

How it works

stack A = Push(c, Push(b, Push(a, Empty))) head → c → b → a → ∅ │ stack B = A.Push(d) head → d─┘ B shares all of A — only one new node stack C = A.Pop() head → b → a → ∅ │ C shares the tail of A — zero allocation the list is a cons list: each node holds a value and a reference to the next. reads, Pops, and tail-sharing all cost nothing.
Zero-allocation Pop
Where ImmutableList and ImmutableDictionary rebuild a path through the tree on every mutation, ImmutableStack's Pop is pure reference arithmetic — it returns the tail of the current head node. No node is created, no GC pressure is added. Push allocates exactly one node. That makes this the fastest immutable collection for pure LIFO work, and the reason so many functional compilers and interpreters pick it as the core stack primitive.

Example

// Construct — factory or LINQ suffix
ImmutableStack<string> s = ImmutableStack.Create("root", "module", "class");
ImmutableStack<string> empty = ImmutableStack<string>.Empty;

// Push — returns a new stack; the old one is still usable
ImmutableStack<string> s1 = s.Push("method");

// Pop overloads — value-and-new, or just new
ImmutableStack<string> s2 = s1.Pop(out string top);
Console.WriteLine(top);                    // "method"

// Peek — inspect the head without popping
string head = s1.Peek();                   // "method"

// Iteration yields items head → bottom (LIFO)
foreach (var scope in s1)
    Console.WriteLine(scope);             // method, class, module, root

// Drain pattern
while (!s1.IsEmpty)
{
    s1 = s1.Pop(out var next);
    Process(next);
}

// Forking histories share tail nodes — cheap branching
ImmutableStack<string> branchA = s.Push("if-branch");
ImmutableStack<string> branchB = s.Push("else-branch");
// both share the entire tail with s — one new node each

// Parser context threaded through productions
ImmutableStack<Scope> TryMatch(ImmutableStack<Scope> ctx, Token t) =>
    t switch
    {
        Token.OpenBlock => ctx.Push(Scope.Block),
        Token.CloseBlock => ctx.Pop(),
        _ => ctx
    };
