HashSet<T>

A hash-based collection of unique values. O(1) average membership testing, O(1) add and remove, and a full suite of set algebra: union, intersection, difference, and symmetric difference. The right default whenever the question is "have I seen this before?"

Contains
O(1)
average, hash-based
Add
O(1)
amortized, rejects duplicates
Remove
O(1)
by value

When to use

Reach for HashSet when membership is the primary question and order does not matter — deduplication, visited-node tracking, set operations on result streams, fast exists-checks. Prefer SortedSet when enumeration should be ordered, and ImmutableHashSet when the set must not change after creation. For thread-safe set behavior, .NET has no direct equivalent — most teams use ConcurrentDictionary<T,byte> as a stand-in.

Set algebra

A = { 1, 2, 3, 4 } B = { 3, 4, 5, 6 } UnionWith → A becomes { 1, 2, 3, 4, 5, 6 } IntersectWith → A becomes { 3, 4 } ExceptWith → A becomes { 1, 2 } SymmetricExceptWith → A becomes { 1, 2, 5, 6 } each operation mutates A in place — O(n + m)

Example

// Create and populate
var seen = new HashSet<string> { "alice", "bob", "carol" };

// Add — returns false when already present, no throw
bool added = seen.Add("dan");       // true
bool dup   = seen.Add("alice");     // false, set unchanged

// O(1) membership test
if (seen.Contains("bob"))
    Console.WriteLine("known");

// Remove by value
seen.Remove("carol");

// Set operations — mutate the receiver
var a = new HashSet<int> { 1, 2, 3, 4 };
var b = new HashSet<int> { 3, 4, 5, 6 };

a.UnionWith(b);                       // { 1, 2, 3, 4, 5, 6 }
a.IntersectWith(b);                   // { 3, 4, 5, 6 }
a.ExceptWith(b);                      // { }

// Predicates — return bool without mutating
bool sub   = b.IsSubsetOf([3, 4, 5, 6, 7]);
bool over  = b.Overlaps([6, 7, 8]);
bool equal = b.SetEquals([6, 5, 4, 3]);

// Case-insensitive string set
var names = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
names.Add("ALICE");
names.Contains("alice");              // true

Equality and hashing

GoalComparer
Default equalityOmit the comparer — uses EqualityComparer<T>.Default.
Case-insensitive stringsPass StringComparer.OrdinalIgnoreCase — fast and culture-neutral.
Culture-aware stringsUse StringComparer.CurrentCulture or InvariantCulture.
Custom typeOverride Equals and GetHashCode together, or supply IEqualityComparer<T>.
