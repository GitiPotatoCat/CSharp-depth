Queue<T>

A first-in, first-out collection. Enqueue appends to the tail, Dequeue removes from the head, Peek looks at the head without removing. Backed by a circular buffer over a resizing array — both ends move in O(1) without shifting elements.

Enqueue
O(1)
amortized, may resize
Dequeue
O(1)
removes head, no shift
Peek
O(1)
reads head, no remove

When to use

Use Queue<T> whenever the oldest element should come out first — job pipelines, breadth-first search, message buffers, ordered event processing. Reach for ConcurrentQueue<T> when producers and consumers run on different threads, BlockingCollection<T> when consumers should wait until work arrives, and PriorityQueue<T,P> when ordering depends on priority instead of insertion time.

How it works

dequeue / peek enqueue ▲ │ │ ▼ ┌──────┬──────┬──────┬──────┬──────┐ │ head │ .. │ .. │ .. │ tail │ └──────┴──────┴──────┴──────┴──────┘ first in last in circular buffer — head and tail advance without shifting any elements

Example

// Create and enqueue
var jobs = new Queue<string>();
jobs.Enqueue("fetch");
jobs.Enqueue("parse");
jobs.Enqueue("write");

// Peek — O(1), does not remove
string next = jobs.Peek();              // "fetch"

// Dequeue — O(1), removes and returns the head
string first = jobs.Dequeue();          // "fetch"

// Safe inspection on possibly-empty queues
if (jobs.TryPeek(out var head))
    Console.WriteLine(head);

while (jobs.TryDequeue(out var item))
    Process(item);                        // "parse", then "write"

// Breadth-first search with a queue
var frontier = new Queue<Node>();
frontier.Enqueue(root);
while (frontier.TryDequeue(out var node))
{
    Visit(node);
    foreach (var child in node.Children)
        frontier.Enqueue(child);
}

// Enumeration yields head → tail (insertion order)
foreach (var j in jobs)
    Console.WriteLine(j);

Queue<T> vs Stack<T>

AspectQueue<T>Stack<T>
OrderFIFO — first in, first out.LIFO — last in, first out.
AddEnqueue(item) appends to the tail.Push(item) places on the top.
RemoveDequeue() takes the oldest.Pop() takes the newest.
EnumerationHead to tail (insertion order).Top to bottom (reverse insertion).
