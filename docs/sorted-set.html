SortedSet<T>

A self-balancing binary search tree of unique values. Every operation is O(log n), enumeration always yields values in sorted order, and the type uniquely supports range views, Min/Max in O(log n), and the full set-algebra suite shared with HashSet.

Contains
O(log n)
tree descent
Add
O(log n)
locate and rebalance
Remove
O(log n)
remove and rebalance

When to use

Use SortedSet when values must be unique and iterated in order — ranked leaderboards, interval indexes, anything that wants GetViewBetween. For membership-only workloads use HashSet<T> — it is faster and uses less memory. For immutable snapshots, reach for ImmutableSortedSet<T>.

Example

// Create and populate — enumeration yields sorted order
var scores = new SortedSet<int> { 72, 88, 95, 91, 84 };
foreach (var s in scores)
    Console.WriteLine(s);         // 72, 84, 88, 91, 95

// Add — returns false when already present
bool added = scores.Add(100);     // true
bool dup   = scores.Add(88);      // false

// Min and Max — O(log n)
int lowest  = scores.Min;
int highest = scores.Max;

// Range view — lives against the same tree
var passed = scores.GetViewBetween(80, 100);
foreach (var s in passed)
    Console.WriteLine(s);         // 84, 88, 91, 95, 100

// Reverse iteration
foreach (var s in scores.Reverse())
    Console.WriteLine(s);         // 100, 95, 91, 88, 84, 72

// Set operations — same surface as HashSet
var a = new SortedSet<int> { 1, 2, 3, 4 };
var b = new SortedSet<int> { 3, 4, 5, 6 };
a.UnionWith(b);                      // { 1, 2, 3, 4, 5, 6 }

// Descending order via comparer
var desc = new SortedSet<int>(
    Comparer<int>.Create((x, y) => y.CompareTo(x)));

AspectBehavior
Live projectionA view returned by GetViewBetween shares storage with the parent — changes on either side are visible in both.
Bounds enforcedAdding an element outside [low, high] through the view throws ArgumentOutOfRangeException.
Inclusive rangeBoth endpoints are included when present.
Lazy enumerationThe view only traverses matching nodes — O(log n) to locate, then O(k) over k results.
