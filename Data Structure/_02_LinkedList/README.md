# LinkedList<T> in C#

Interactive documentation for C#'s doubly-linked list, built for **.NET 10** / **C# 14**.

## ▸ [Open the interactive documentation](https://gitipotatocat.github.io/CSharp-depth/)

Features a live linked-list playground, tabbed code examples for every
core operation, a side-by-side complexity matrix vs `List<T>`, and a
full LRU cache implementation.

---

## Preview

- Visual playground — click `AddFirst` / `AddLast` / `RemoveFirst` / `Find` and watch pointers rewire
- Six tabbed operations with complexity badges
- Ten-row complexity matrix
- Modern C# 14 idioms (collection expressions, pattern matching, primary constructors)
- Four common pitfalls with safe-deletion patterns

## Stack

- .NET 10 · C# 14
- Vanilla HTML / CSS / JavaScript (no build step, no frameworks)
- Typography: Instrument Serif, IBM Plex Sans, IBM Plex Mono
